# DGSLT

DGSLT: A Privacy-Preserving and Accountable Blockchain-Based Land Titling Framework Using Decentralized Group Signatures.

## Overview

This repository contains the prototype implementation and experimental artifacts used in the paper:

DGSLT: A Privacy-Preserving and Accountable Blockchain-Based Land Titling Framework Using Decentralized Group Signatures

## Components

- Solidity smart contracts
- DGSS cryptographic implementation
- Experimental scripts
- Performance evaluation datasets

## Environment

- Solidity
- Hardhat
- Node.js
- Python 3.x

## Reproducing Experiments

Instructions for reproducing the experiments are provided in the corresponding folders.
